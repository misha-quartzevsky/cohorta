# Experiments

Артефакт журнея `/improve-app` (создан в фазе 2, 2026-08-29). Каждое изменение UI/копирайта
попадает сюда карточкой с заранее зафиксированной метрикой до того, как уходит в работу.

**Режим прогона: сначала только доки.** Код не трогаем; ниже — приоритизированный бэклог.
Правки стартуют отдельной сессией после утверждения очередности.

**Данных о пользователях нет** → метрики прокси, замеряются вручную по сценарию «новый
студент»: число шагов до первого конспекта, число шагов до первой карточки, число экранов
без рабочего пустого состояния, число тупиков (экранов без выхода), число отклонений от
токенов `/DESIGN.md`.

ICE: Impact / Confidence / Ease, каждый 1–10; score = I×C×E / 100 (0–10).

## Experiment Cards

### EXP-001 — Экран «Новый семестр» из пустого состояния
- Hypothesis: Новый пользователь дойдёт до первого конспекта в первую сессию, если сможет
  создать семестр внутри приложения (а не в админке PocketBase), потому что сейчас это
  единственный жёсткий блокер Big Hire.
- Type: sprint (правка UI) + модерируемый прогон «новый студент»
- Primary metric & threshold (pre-committed): 5 из 5 тестовых прогонов «чистый вход →
  первый конспект» завершаются без выхода из приложения; шагов до «семестр создан» ≤ 2.
- Guardrail metric: не появляется новый экран-тупик; число шагов до первого конспекта
  суммарно не растёт.
- Decision rule: 5/5 → persevere (в работу); 3–4/5 → iterate (упростить); ≤2/5 → pivot
  (пересмотреть модель «семестр как контейнер»).
- Result & verdict: _(pending — код не трогаем в этом прогоне)_

### EXP-066 — Единый парсер дат PocketBase
- Hypothesis: «битые» даты в редакторе — это `new Date()` на формате PocketBase с пробелом
  вместо `T` (не ISO-8601); Chrome прощает, Firefox/Safari дают `Invalid Date`, и
  `formatDate` печатает сырую строку, `timeAgo` — пустоту.
- Type: bugfix + регрессионный тест Playwright.
