## Git и деплой

- Всё закоммичено в ветку **`design/wave-a-b1`** (от `main`), 8 коммитов: докс-материалы → A0.5 миграции PocketBase + groupService.ts → A1 токены/шрифт → A2 бренд-ассеты → A3 компоненты → A4 каркас → B1 Главная → B1 редактор. В `main` ничего не вливалось.
- Ветка **запушена**, на Cloudflare Pages должен появиться preview-деплой по пушу (git-интеграция уже настроена).
- **Устарело (проверено через API 20.10):** в настройках Cloudflare Pages для Preview переменных сейчас нет вовсе (ни `VITE_NEW_UI`, ни `VITE_PB_URL`), поэтому preview-сборки показывают старый интерфейс и ходят на `127.0.0.1:8090`. Решение владелицы ждётся: включить их (и тогда сначала накатить миграции и хуки B6 на Amvera) или смотреть локально.
- Начиная с волны **B2 — одна ветка на каждую секцию** (решение владелицы), прошлое (A0–B1 одним заходом) не переписывается.
- **Ветка `design/b2-lectures-search`** (от `design/wave-a-b1`), запушена, должен появиться Cloudflare Pages preview по пушу.
- PocketBase на Amvera обновлён отдельно (3 миграции закоммичены напрямую в git Amvera-проекта и применены на проде) — те же файлы теперь есть и в этом репозитории (A0.5-коммит), синхронизация устранена.
- **Бэкап прод-`pb_data` на Amvera НЕ делался** ни разу — нет доступа к файловой системе персистентного диска через доступные инструменты (только к git-репозиторию кода). Нужен SSH/SFTP-доступ или суперюзер-пароль PocketBase, чтобы сделать его перед следующими изменениями схемы.

Вероятная причина: iOS Safari увеличивает страницу при фокусе в поле со шрифтом меньше 16 px (у наших полей 14 px, а в шторке «Новый предмет», шторке периода и поиске курсор ставится в поле сразу). Поля на телефоне и планшете теперь 16 px; поля в шторках на всю ширину. На самом iPhone не проверено.
2. **«Занятия».** Числа считались из данных, но пока данные грузились (или загрузка не удалась) показывался «0». Теперь пока грузится — пусто, при ошибке — «Не удалось загрузить».
3. **Три одинаковых «Предложено».** Это были три разные лекции (вчерашние, без прохождений), а в строке стоял один и тот же текст без названия. Теперь «Квиз по вчерашней лекции: Лекция 1 · Статистика» (название лекции и предмет), «· 8 вопросов» убрано (число было вписано в код, а размер квиза выбирают 5, 8 или 12). Одна лекция, пришедшая дважды, даёт одну строку.
4. **Главная, «Продолжить».** На телефоне нет кнопки: вся карточка нажимается, справа стрелка, как в `Screen-dashboard-mobile`; название и предмет переносятся. На компьютере кнопка «Открыть лекцию» осталась.
5. **«Задачи» на телефоне.** Дата под названием и предметом, «···» не сжимает название; вкладки (13 px, отступы 12 px) помещаются.
