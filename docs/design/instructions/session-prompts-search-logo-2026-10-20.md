# Волна «Поиск и логотип в сайдбаре» (20.10)

Сначала прочитай `userflow-decisions-2026-10-19.md`, раздел «Дополнение 20.10 (вечер): поиск и логотип в сайдбаре». Он важнее строк про поиск в `migration-instruction-for-claude-code.md` (A4, B2) и в `userflow.md`.

Ветка: design/search-sidebar. Отдельная небольшая волна, можно делать между B2 и B5.

Что сделать:
1. Десктоп. Убери строку поиска из верхней шапки. В сайдбаре под логотипом добавь поле «Поиск» (40 px, фон `--sunken` #EEEEEB, без обводки, лупа слева, подсказка «⌘K» справа на белой плашке; при фокусе стандартное кольцо; по нажатию на поле или по ⌘K / Ctrl+K открывается поиск). Режим «Группа» то же.
2. Логотип в сайдбаре: высота 16 px, одноцветная тёмная версия (`cohorta-logo-mono-ink.svg`), левый край точно по левому краю значков меню (не по центру и не со сдвигом, как сейчас на живом). Это сознательное исключение из правила 24 px (решение Маргариты, записано в `logo-usage-rules.md`).
3. Телефон. Вкладка «Ещё» теперь «Занятия» (значок layout-grid). Иконка лупы (22 px, без рамки, зона нажатия 44 px) в правом верхнем углу корневых экранов: Главная, Расписание, Лекции, Занятия; в группе Люди, Доступ, Экзамены. Рядом с кнопкой «+» лупа правее. Нажатие открывает экран поиска. Из «Занятия» убери строку «Поиск».
4. Удали локальные поля поиска в «Все лекции», «Лекции предмета», «Черновики», «Люди». Фильтры-пилюли и период остаются.
5. Экран поиска: ищет по лекциям, предметам, одногруппникам; чужие лекции только по названию (без изменений).

Макеты: Foundation-shell, Screen-lectures, Screen-subject-lectures, Screen-m-lectures-all, Screen-dashboard-mobile, Screen-m-more, Screen-m-group-people (открой html и png).

Проверки: Tab доходит до поля поиска, ⌘K работает, на телефоне зона нажатия 44 px, на 360 px ничего не уезжает. Скриншоты рядом с макетом.
