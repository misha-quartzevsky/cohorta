## Правило (решено 19.10, оно уже в decisions.md)
У человека один экзамен на предмет. Если в его группе есть экзамен по этому предмету, личный экзамен присоединяется к групповому: список билетов общий, ответы у каждого свои. Кнопка «Взять мой ответ» копирует личный ответ в билет подгруппы.
