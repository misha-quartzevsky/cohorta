## Задача 2. Исправить импорт билетов (соло и группа, экран один)

Ориентиры: Screen-ticket-import, Screen-m-ticket-import, Screen-m-ticket-add (макет добавления билета на телефоне). Сейчас импорт работает криво, я проверила руками.

1. Нумерация. Цифры, которые стоят в начале строк вставленного текста, не являются номерами билетов. Убирай их. Форматы: «1.», «1)», «1 –», «1 —», «1:», число и пробел, табы и несколько пробелов после номера, маркеры «•», «-», «*». Пример: из «12) Оферта и акцепт» получается «Оферта и акцепт». Новые билеты получают следующие номера после уже существующих (если есть 1–3, новые идут 4, 5, 6…), порядок как в тексте. Статус «Номер занят» и пропуск строк убери полностью. Все непустые строки добавляются. Пустые строки пропускаются, пробелы по краям обрезаются. Одинаковые названия не склеиваются: два одинаковых названия это два билета.
2. Предпросмотр справа: показывай номер, который получит билет (4, 5, 6…), текст билета и пометку «Новый». Подпись над списком «Найдено N билетов» (как в макете телефона, с правильным склонением: 1 билет, 2 билета, 5 билетов) вместо «Разобрано по строкам…». Кнопка «Добавить N билетов» с тем же N, что в списке (сейчас было 27 и 24).
3. Шапка страницы с кнопкой «Добавить N билетов» остаётся видимой при прокрутке длинного списка (sticky). Одна оранжевая кнопка на экране.
4. Поле вставки: убери ручку изменения размера (resize: none), высота по содержимому, минимум около 200px. Пустое состояние: подсказка в поле и «Здесь появится список после вставки», кнопки «Добавить» нет, пока нет ни одной строки.
5. Подпись под заголовком такая же, как на странице экзамена: «<Предмет> · экзамен 12 января», а если даты нет, «<Предмет> · дата экзамена не задана».
6. Тесты: разбор списка с форматами «1.», «1)», «1 –», «1:», с табами, с маркерами, с пустыми строками, при уже существующих билетах 1–3 (новые получают 4…), список из 27 строк даёт 27 билетов с номерами подряд, ни одна строка не пропущена из-за «занятого номера».
