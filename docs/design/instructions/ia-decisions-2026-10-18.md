# Cohorta — решения по информационной архитектуре (2026-10-18)

Ответы владелицы на шесть вопросов из разбора `ux-critique-and-ia-2026-10-17.md` (раздел «Открытые вопросы» там устарел, действует этот файл).

1. «Курс» в группе заменить на «предмет». Курс означает только год обучения.
2. У «Карточек» своя вкладка на телефоне.
3. Поиск по продукту нужен к первому запуску. Строка в шапке, ищет по лекциям, предметам и одногруппникам.
4. На один экзамен человек состоит только в одной подгруппе.
5. В двух группах можно состоять одновременно, обе активные.
6. Вступление по коду без одобрения: да, всё закрыто по умолчанию.

## Что из этого следует
- Нижняя панель Соло на телефоне: Главная, Задачи, Расписание, Лекции, Карточки (5 вкладок). «Предметы» отдельной вкладки не имеют: открываются из «Лекции» (ряд предметов сверху).
- Нижняя панель Группы на телефоне: Люди, Доступ, Экзамены, Профиль. Название текущей группы в верхней полосе, по нажатию открывается переключатель групп.
- Меню на компьютере: у карточки группы есть переключатель, в нём список групп и «Вступить в ещё одну».
- Участник (членство) принадлежит конкретной группе. Предпросмотр, доступы, экзамены и подгруппы настраиваются отдельно для каждой группы. «Мой доступ» показывает текущую группу.
- Один и тот же человек может быть в подгруппах двух разных групп. На один экзамен подгруппа одна.
- Не нарисовано: переключатель групп (раскрытый), «Карточки» на новой основе, мобильные экраны группы, экран поиска.
- Для данных: «Участник» и «Доступ» связаны с группой, а не только с пользователем. Правила доступа проверяются на сервере для каждой группы отдельно.
