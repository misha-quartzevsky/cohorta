Кнопка действия. Одна главная (`primary`, оранжевая) на экран: «Начать конспект», «Войти», «Ответить». Остальное `dark`, `secondary`, `ghost` или `soft`.

- `primary`: заливка `accent`, текст `on-accent` (белый, жирность 600, 3.3:1). При наведении `accent-hover` (темнее, 4.0:1).
- `dark`: чёрная (`ink`), для второго по важности действия, когда `secondary` слишком тихая. Не ставить рядом с `primary` как равную.
- Высота 44 px (`control-md`), малая 36 px, большая 52 px для одиночного действия на форме. На телефоне главная кнопка на всю ширину.
- `soft` с текстом `accent-strong` для мягких действий вроде «Продолжить учёбу».
- `danger` только внутри окна подтверждения, не в основном интерфейсе.
- Недоступная кнопка серая и объясняет причину рядом, а не только тускнеет.
- Фокус с клавиатуры: обводка `ink` 2 px с зазором.

Классы: `c-btn primary|dark|secondary|ghost|soft|danger`, размер `sm` или `lg`.
