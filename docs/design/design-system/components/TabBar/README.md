Нижняя панель телефона: 3–5 пунктов с подписями. Соло: Главная, Задачи, Расписание, Лекции, Карточки. Группа: Люди, Доступ, Экзамены, Профиль.

- Активная вкладка отмечена оранжевой чертой сверху и чёрной иконкой, не цветом текста.
- Зона нажатия 44 px и выше. Предметы на телефоне открываются из вкладки «Лекции» чипами сверху.
- Название группы в верхней панели открывает переключатель групп нижней панелью.
