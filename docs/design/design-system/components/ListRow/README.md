Строка списка: лекции, задачи, билеты, одногруппники. Список, а не сетка плиток, для всего, что читают подряд.

- Минимум 64 px (`row-min`). Слева обложка 40×40 (`radius-md`) или аватар, по центру название (`list-title`) и мета (`meta`, `ink-3`), справа один бейдж и шевроны.
- Выбранная строка заливается `accent-soft`, без рамки и без полоски слева.
- Одинаково для своих лекций и лекций одногруппников: у чужих вместо обложки миниатюра-листок, вместо бейджа «Открыта тебе» или «Запросить доступ».
- Строки внутри одной рамки `radius-lg` без теней.

Классы: `c-list`, `c-row` (`on`), `.cv cover-civil|mkt|stat|phil`, `.tx .t .m`.
