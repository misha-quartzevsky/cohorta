Обложка предмета: мягкий градиент из трёх цветовых пятен на светлом фоне. Единственное место в интерфейсе, где допустимы градиенты.

- **Создаётся автоматически.** У предмета хранится одно число `cover_seed` (оттенок 0–359), и больше ничего. Класс `c-cover` строит градиент из переменной `--h`: `<span class="c-cover" style="--h:212">`. Яркость и насыщенность фиксированы, поэтому все обложки выглядят как одна семья.
- Число присваивается один раз при создании предмета: `round((20 + N * 137.5) mod 360)`, где N это число предметов пользователя. Первые 12 предметов гарантированно разные. При переименовании предмета цвет не меняется.
- В группе обложка предмета одногруппника берётся из его `cover_seed`, поэтому у всех она одинаковая.
- Классы `cover-civil`, `cover-mkt`, `cover-stat`, `cover-phil` (оттенки 20, 335, 135, 212) остались только для примеров в макетах.
- Текст поверх обложки только `ink` или `ink-2`. `ink-3` на градиенте даёт 4.16:1, не использовать.
- Размеры: 16–22 px в меню, 40 px в строке, 96 px и больше на странице предмета. Логотип на обложку не ставится.
