Всё, что появляется поверх экрана: меню, окно, тост. Только они получают `shadow-pop`.

- Необратимое действие спрашивает окном подтверждения (`radius-xl`, кнопка `danger` справа). Обратимое просто выполняется и показывает тост с «Отменить».
- Опасный пункт меню отделён линией и красный только текстом (`danger-text`).
- На телефоне меню открывается нижней панелью (`radius` 24 сверху, пункты 52 px).
- Esc закрывает любое всплывающее.
