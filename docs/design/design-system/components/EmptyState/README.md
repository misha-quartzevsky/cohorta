Пустое состояние: что здесь будет и одно действие. Пунктирная рамка `line-strong`, иконка на `sunken`.

- Заголовок называет, чего нет («Пар пока нет»), текст говорит, что делать. Без извинений.
- Одно действие, главная кнопка, если на экране нет другой главной.
- Системные состояния (загрузка, нет связи, ошибка, закрытая лекция) оформляются так же: скелетон повторяет форму списка, ошибка не стирает данные, закрытая лекция даёт «Запросить доступ».
