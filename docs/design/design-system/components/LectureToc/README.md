Содержание лекции в левой колонке. Пока открыта лекция, заменяет список предметов. Над ним строка возврата к предмету.

- Строится из заголовков H2 и H3 текста. H3 с отступом и мельче. Текущий раздел отмечен точкой `accent` и подложкой `surface`, следует за прокруткой.
- Нажатие прокручивает текст к заголовку.
- Длинный список прокручивается внутри колонки, внизу тонкая тень. Нет заголовков: подсказка «Добавь заголовок, и он появится здесь».
- На телефоне открывается нижней панелью из верхней панели редактора, пункты 48 px.

Классы: `c-toc`, `a.h3`, `a.on`.
