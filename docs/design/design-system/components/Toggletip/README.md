Лампочка в шапке экрана для объяснений. Заменяет статичные поясняющие панели справа.

- Кнопка 44×44 с подписью для чтения с экрана («Как работает …»), открывается по клику и Enter, закрывается Esc и кликом вне.
- Для коротких необязательных пояснений достаточно `title` (tooltip). Информация, без которой можно ошибиться (например, что подгруппу не видят остальные), остаётся видимой строкой на экране, не прячется в лампочку.
- Содержимое 2–4 коротких предложения.
