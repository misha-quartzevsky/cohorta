Поле ввода. Подпись всегда над полем, не внутри: плейсхолдер исчезает при вводе.

- Рамка `input-border` (контраст ≥3:1), фокус: рамка `ink` и кольцо `accent-soft`.
- Ошибка: рамка `danger` и текст под полем цветом `danger-text`. Цвет без текста не используется.
- Подсказка под полем `meta`, цвет `ink-3`.
- Высота 44 px. Не использовать `line` для рамки поля.

Классы: `c-field`, `c-field err`.
