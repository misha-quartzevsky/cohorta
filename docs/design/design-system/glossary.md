# Словарь и правила интерфейса

Одно слово на одну вещь во всём интерфейсе и в коде.

| Слово | Что значит | Не говорим |
| --- | --- | --- |
| Соло | Личное пространство: записи, задачи, расписание, экзамены | личный режим |
| Группа | Общее пространство одногруппников, например МК-31 | когорта, класс |
| Предмет | Дисциплина семестра. Курс остаётся только годом обучения | курс |
| Лекция | Запись занятия: название, номер, дата. Строка в списках | заметка, страница |
| Конспект | Текст внутри лекции | записи |
| Квиз | Вопросы по тексту одной лекции для проверки себя | тест, опрос |
| Готовность лекции | Процент по ответам квиза и давности. Билеты не входят | прогресс |
| Готовность к экзамену | Сколько билетов предмета готово | просто «готовность» |
| Билет | Один вопрос экзамена и ответ на него | вопрос, карточка |
| Предпросмотр | Группа видит названия лекций, но не текст | превью |
| Доступ | Право читать текст одной лекции, человеку или подгруппе | шеринг |
| Подгруппа | Круг подготовки к одному экзамену внутри группы | команда |
| Карточки | Раздел повторения, один набор называется «колода» | флешкарты |

## Правила доступа в группе

- Всё закрыто по умолчанию. Предпросмотр включается вручную, отдельно для каждой группы. Текст лекции открывается по одной лекции.
- Убрать доступ так же просто, как дать: у каждого человека своя кнопка «Убрать».
- Подгруппу видят только её участники. На один экзамен человек состоит в одной подгруппе.
- Правила доступа должны стоять на сервере (в правилах базы), а не только в интерфейсе: запрос чужой лекции без выданного доступа возвращает отказ.
