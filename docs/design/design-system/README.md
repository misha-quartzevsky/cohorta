cohorta (говорим «когорта», пишем латиницей со строчной): PWA для студентов, конспекты, задачи и подготовка к экзаменам. Русский интерфейс, нейтральный светлый фон, фирменный оранжевый #E86800, знак Δ, шрифт Inter, никаких градиентов кроме обложек предметов.

## Бренд

- Характер: ответственный староста-активист. Организует, помогает с радостью, но списать не даст, ценит себя. Три слова: вовлекающий, поддерживающий, удобный. Никогда: отвлекающий.
- Название: «cohorta» со строчной везде, как в логотипе. Произносится «когорта». В интерфейсе объединение людей называется «группа», не «когорта».
- Тон: в интерфейсе сдержанно и конкретно; в маркетинге и медиа живее, но тем же голосом.
- Цвет бренда один снаружи и внутри: `accent` #E86800 (Pantone Exuberance). Фирменная пара: оранжевый + почти чёрный `ink`. В интерфейсе фон нейтральный светлый (`bg`); тёплый кремовый #F2EEE8 только в бренд-материалах (стикеры, соцсети, мерч), чтобы продукт не напоминал тёплый бежевый визуальный язык Claude.
- Логотип: знак Δ (типографская дельта, «изменение» = прогресс) + надпись «cohorta» шрифтом Non Pliant. Надпись существует только как готовый SVG из группы ассетов «Logos», никогда не набирается текстом. Правила: `logo.md`.

## Содержательные принципы

- Говорить на «ты», коротко и по делу. Кнопка называет действие («Начать конспект», «Запросить доступ»), ошибка говорит, что случилось и что делать. Без эмодзи, восклицаний и извинений.
- Слова строго по словарю (`glossary.md`): «предмет» (не «курс»), «лекция» (запись), «конспект» (текст внутри), «квиз», «билет», «предпросмотр», «доступ», «подгруппа».
- Режимы: «Соло» личное, «Группа» общее. В группе всё закрыто по умолчанию: вступление ничего не открывает.

## Визуальные основы

- Фон страницы `bg`, карточки и строки `surface`, углубления `sunken`. Текст `ink`, вторичный `ink-2`, третичный `ink-3`.
- Оранжевый `accent`: заливка главной кнопки, логотип, маркер активного пункта, индикатор вкладки, точки. Текст на оранжевом белый `on-accent`, жирность 600. Оранжевый текст (ссылки, активный пункт, «сегодня») только `accent-strong`.
- Одна главная кнопка на экран: `primary` (оранжевая). Остальные `dark`, `secondary`, `ghost`, `soft`. Оранжевая заливка не повторяется на экране больше одного раза.
- Красный `danger` только для alert-объектов: слабая тема, просрочка, ошибка. Красный текст `danger-text`. Ссылки никогда не красные. Зелёный `ok` для «Готово» и верного ответа.
- Заголовок страницы `display`, заголовок экрана телефона `h1`, раздел `h2`, строка списка `list-title`, мета `meta`, метки секций `label` заглавными.
- Содержимое страницы не шире `content-max` (1120 px), левое меню `sidebar-width` (264 px), поля `space-10`, зазоры между карточками `space-4`–`space-6`.
- Скругления: `radius-md` кнопки и поля, `radius-lg` карточки и списки, `radius-xl` окна, `radius-pill` бейджи. Тень `shadow-pop` только у меню, окон и подсказок.
- Статус всегда точка и слово. Список, а не плитки. Без рамок-полосок слева у карточек, без свечений, без градиентов вне `SubjectCover`.
- Зона нажатия на телефоне не меньше `touch-min` (44 px). Нижняя панель 3–5 пунктов с подписями. Любой экран достижим не больше чем за 3 нажатия.
- Контраст: основной текст не ниже 4.5:1, рамки полей и значимые границы не ниже 3:1 (`input-border`). Фокус с клавиатуры виден всегда.

## Образцы экранов

Макеты всех экранов (десктоп и телефон), состояния и мобильные версии лежат на холсте «Cohorta Editor» (артефакт Design). Карта продукта, сценарии, объекты и правила доступа лежат в артефакте с информационной архитектурой. Новый экран строить из компонентов этой системы и сверять с похожим макетом.

## Как использовать в коде

Токены брать из `tokens.json` и `tokens.css`, компоненты из `components/bundle.css` (классы `c-btn`, `c-field`, `c-chip`, `c-list`/`c-row`, `c-seg`, `c-pills`, `c-pop`, `c-toc`, `c-empty`, `c-tabbar`). Значения не копировать числами в стили: ссылаться на `var(--имя)`.
