Основа: компоненты

Каждый компонент показан в тех состояниях, в которых его увидит студент: обычный, наведение, фокус с клавиатуры, недоступный, ошибка, загрузка.

Кнопки

Одна главная кнопка на экран (оранжевая, текст белый). Чёрная — для второго по важности действия. Мягкая — для «продолжить учёбу». Опасное действие красным только в подтверждении, не в основном интерфейсе. Минимальная высота 44 px: зона нажатия.

Поля ввода

Подпись всегда над полем, а не внутри (подсказка внутри исчезает при вводе). Ошибка: цвет + текст, не только цвет. Фокус: тёмная рамка и мягкое кольцо.
