# Positioning & Messaging

Артефакт журнея `/improve-app`. Фаза 6 (made-to-stick, 2026-08-29) заполнила
`## Key Messages` — тексты внутри приложения. Позиционные секции ниже — лёгкие заглушки
(журней про опыт, не про рынок); полный разбор сегмента и альтернатив — в `docs/CUSTOMER.md`.

Словарь (решение фазы 2): объект — **«конспект»**, обращение — **«ты»**.
Решения фазы 6: **без обещаний времени** («10–20 минут» и т.п. не пишем); термины
объясняются **одной строкой в пустом состоянии** раздела (исчезает, когда есть данные).

## Best-Fit Customer
Студент вуза, ведёт несколько предметов за семестр, к сессии сдаёт билеты. Хочет
держать ритм, а не зубрить в ночь. Подробный портрет — `docs/CUSTOMER.md`.

## Market Category
Подкатегория: «конспекты + повторение для студентов» (между заметочником типа Notion и
SRS-тренажёром типа Anki). Не переопределяется в этом журнее.

## One-Liner
Черновик (из работы фазы 1, без имени продукта в основе):
**«Конспекты, карточки и билеты одного семестра — на одном экране, чтобы к сессии всё
уже было готово».**

## Brand Script (StoryBrand)
_(не в фокусе этого журнея; каркас для будущей работы)_
- Character: студент в семестре, материал копится.
- Problem (внешн.): три несвязанных инструмента; (внутр.): тревога «не успею»;
  (философ.): готовиться к экзамену должно быть про понимание, а не про панику.
- Guide: продукт, который связывает запись → повторение → готовность.
- Plan: заведи семестр → пиши конспекты → собери карточки → веди билеты.
- Call to action: «Заведи семестр».
- Failure: ночь перед экзаменом, зубрёж.
- Success: пришёл на сессию с готовыми ответами.

## Key Messages

Surface = экран внутри приложения. SUCCESs 1–10 по каждому из шести; показан текущий
балл проблемных и переписанный вариант. Все переписи — словарь «конспект» + «ты»,
без обещаний времени.

### Commander's Intent по экранам (одно, что должен донести экран)

| Экран | Одно, что должен донести |
|---|---|
| Login | Здесь весь твой семестр — войди |
| Пустой дашборд (онбординг) | Заведи семестр — и сразу пиши первый конспект |
| Дашборд (с данными) | Продолжи с того места, где остановился |
| Пустой курс | Добавь первый конспект по этому предмету |
| Редактор конспекта | Пиши — сохранится само |
| Библиотека колод (пусто) | Собери карточки из конспекта и повторяй их |
| Прохождение колоды | Повтори карточки этой колоды |
| Центр экзамена (пусто) | Загрузи билеты — увидишь, что готово и что осталось |
| Центр экзамена (данные) | Осталось N билетов до готовности |
| Импорт билетов | Вставь список билетов — по одному в строке |
| Правка билета | Напиши ответ — статус обновится сам |
| Шпаргалка | Все готовые ответы на одной странице — для последнего повтора |
