# Design System

Артефакт журнея `/improve-app` (создан в фазе 2, 2026-08-29). **НЕ путать с корневым
`/DESIGN.md`** — та остаётся источником правды по токенам и компонентам. Здесь копятся
находки UX-аудита (фазы 2–3), решения по токенам/компонентам (фаза 4), инвентарь
микровзаимодействий (фаза 5) и строки производительности (фаза 8, отложена).

Ссылки на строки кода даны от `apps/web/src/`. Приоритеты: **P0** — верх бэклога,
следующая сессия правок; **P1** — сразу за P0; **backlog** — по мере.
Решение пользователя (фаза 2): P0 = ядро цепочки + потеря данных; остальные S3 → P1; S2 → backlog.

## Design Direction

**Сигнатурный элемент — уже есть и работает:** двухслойная карточка курса с градиентной
рамкой (`/DESIGN.md §5`). Не трогаем, распространяем.

**Характер:** спокойный рабочий инструмент студента, не игра. Один бренд-градиент, плоские
поверхности, без стекла (`/DESIGN.md §0, §1.7`). Фаза 4 **не переизобретает систему** —
чинит отклонения кода от неё (решение пользователя: новые токены можно, но сначала
расширяем `/DESIGN.md`, потом код).

**Иерархия дашборда (решение пользователя, 2026-08-29): один герой = «продолжить
конспект».** Самое частое действие сейчас; работает без нового функционала. Остальные
6 блоков — вторичный вес (меньше, легче, спокойнее). `PriorityHero` перестаёт конкурировать
двумя равными ветками (экзамен vs продолжить): «продолжить» — всегда герой, «ближайший
экзамен» — компактная строка-контекст под ним, а не второй hero. (Когда фаза 9 решит про
SRS — пересмотреть: кандидат в герои «повторить сегодня».)

**Blur-тест ключевых экранов:**
| Экран | Что доминирует при squint | Вердикт |
|---|---|---|
| Дашборд | 7 блоков сопоставимого веса | FAIL → один герой (см. выше) |
| Карточка курса | градиентная рамка = принадлежность | PASS |
| LectureEditor | свой topbar ⟷ контент (два якоря) | FAIL → см. U5 (общий каркас) |
| ExamHub | верх часто пустой (h1 = "") | FAIL → заголовок-фолбэк «Экзамен · курс» |

## Typography

Действует `/DESIGN.md §2`: Inter 400/500/600 для UI; sentence case; display-шрифт
сдержанно. Фаза 4 фиксирует нарушения:

- **19 вхождений `font-weight: 700/800`** в UI-хроме (`App.css`) против §2 «не 700 в
  UI-хроме». Три веса (600/700/800) на соседних заголовках → свести к **600** для всех
  UI-заголовков; **700** допустим только в теле конспекта (`.lecture-view-content strong`,
  h1/h2 внутри пользовательского текста — это контент, не хром).
- **h1 разнобой:** `.page-title`/`.hero-greeting` 24px (комментарий сам признаёт дрейф),
  `.lecture-view-title` 800/1.875rem, `.tiptap h1` 1.5rem/700. Свести UI-h1 к **§2: 22px/600**.
- **«Golos UI»** на `.exam-hero-title`, `.exam-cheatsheet-question` (`App.css:4503,4596`) —
  недокументированное третье семейство. Убрать → Inter (UI) или display-токен (см. Tokens).
- Тело конспекта — сейчас Inter; кандидат-скилл `web-typography` отложен: включить, если
  на реальных длинных конспектах чтение окажется тяжёлым (мера: строка > 75 символов,
  line-height < 1.5 в `.lecture-view-content`).

## Tokens

**Правило:** grayscale-иерархия сначала (размер/вес/контраст), цвет — последним.
Действующие токены — `/DESIGN.md §1, §3, §1.6`. Работа фазы 4 = **замена отклонений на
существующие токены**, плюс 2 предложенных добавления в `/DESIGN.md`.

### Signature Moment: «Повторение на сегодня закрыто»

Removal-тест: без него продукт ощутимо хуже — это эмоциональное ядро привычки «учиться
регулярно» (закрыл сегодняшнюю порцию → спокойствие «я не отстаю»).

- **Инструменты:** копирайт + сдержанная анимация (без конфетти, без эмодзи — `/DESIGN.md §0`).
  «Готово на сегодня. Вернёмся завтра — N карточек.» Плавное «схлопывание» очереди в галочку.
- **Зависимость:** нужен SRS / понятие «порция на сегодня». **Решает фаза 9** (строим ли
  расписание повторений). Если SRS не входит в MVP — сигнатурный момент переносится на
  «прошёл колоду целиком» (`FlashcardPlayer` финал), очищенный от геймификации.
- **Где:** дашборд (`ReviewBlock` перестаёт быть «Колоды», становится «На сегодня») +
  финальный экран прохождения.
- **Не блокировать:** тап сквозь анимацию всегда работает.
