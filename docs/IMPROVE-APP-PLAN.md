# Improve App Plan

## Context
- **Приложение:** Cohorta — локальная edtech PWA (Vite + React + TS, backend PocketBase). Студент ведёт конспекты лекций по семестрам/курсам, собирает из них карточки (flashcards) и готовит ответы на билеты к экзамену.
- **Главная работа (со слов пользователя):** «Учиться регулярно» — держать ритм: конспект → карточки → повторение в течение семестра, а не собирать всё в ночь перед экзаменом.
- **Где грубо:** запутанные экраны, мёртвые взаимодействия, любительский вид, слабые тексты (по ощущению — данных о поведении пользователей нет).
- **Данные:** нет (recordings / tickets / analytics отсутствуют). Стадия — проработка MVP, реальных пользователей пока нет.
- **Платформа:** web PWA, локальный запуск. Нативного iOS нет.
- **Монетизация:** нет. Upsell-поверхностей нет.
- **Существующие доки:** `/DESIGN.md` (подробная дизайн-система с токенами), `/TEST_PLAN.md`, `/README.md`. Нет `docs/CUSTOMER.md`, `docs/POSITIONING.md`, `docs/PRODUCT.md`, `docs/EXPERIMENTS.md`.
- **Начато:** 2026-08-29
