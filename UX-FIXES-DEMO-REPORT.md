### 6. Группа без названия в списке `/group`  — расследование

(`groupService.createGroup`) всегда пишут непустое `name.trim()`; UI не даёт создать без

Вывод: строка с пустым заголовком в `/group` — это **аномалия данных** (легаси-строка до
включения `min:1`, либо ручная правка в админке), а не задизайненное поведение.
Правка кода: `lib/types.ts` → `groupName()` теперь трактует `""`/пробелы как отсутствие
имени и отдаёт «Группа» (раньше фолбэк срабатывал только на `null`/`undefined`, пустая
строка рендерилась как пустой `<h3>`).
**Что нужно от вас — см. «Бутылочные горлышки» ниже (проверить саму строку в БД).**

### 9. Drag-n-drop — диагностика + фикс
Версии `@tiptap/*` — все `3.30.1`, дедуплицированы, рассинхрона НЕТ (первый подозреваемый
из плана снят). Живая диагностика (Playwright + консоль, фиксировано на свежем Firefox):

| Место | Находка |
|---|---|
| **Реордер блоков в редакторе (Tiptap drag handle)** | **БАГ найден и починен.** Грип-элемент в DOM есть, но `opacity:0` и **никогда не появлялся**: CSS раскрывал его только по `.editor-drag-handle:hover` — а сам грип стоит `position:absolute; left:-24px`, в 24px-полосе слева от текста, **вне `.tiptap-wrapper`**. До невидимого элемента там курсор не доводят → грип не виден нигде → «drag-n-drop не работает». Фикс (`App.css`): грип раскрывается по `.tiptap-wrapper:hover` (указатель над «листом»), плагин и так ставит его напротив нужного блока. После фикса диагностика: `opacity` → `1` при наведении на текст. |
| **Реордер карточек колоды (@dnd-kit)** | Обвязка на месте: `DndContext` + `SortableContext` + `useSortable`, `{...attributes} {...listeners}` на грипе `.deck-card-drag`, `PointerSensor` distance 4. Дефекта в коде не видно. Синтетический drag в Playwright реордер не воспроизвёл — **это известное ограничение** (`docs/EXPERIMENTS.md` EXP-065: `@dnd-kit` DnD в headed-Firefox не гоняется тестом). **Требуется ручная проверка — см. ниже.** |
| **Ресайз/реордер колонок таблиц** | Реордера колонок/строк в продукте **нет и не задумывался** — только `columnResizing` (`TableExtension.configure({ resizable: true })`, `.column-resize-handle`), он работает. `TableMenu` = добавить/удалить строку/колонку. Багa нет. |

## ⚠️ Бутылочные горлышки — обязательно проверить руками

1. **П2, редактор — вставка картинки и схемы.** Автотестов визуалки нет. Открой конспект,
   вставь картинку (перетаскиванием и через `/`→«Картинка») и схему Excalidraw:
   - обе должны быть в одинаковой карточке (рамка, скругление, лёгкая тень);
   - иконки «карандаш / корзина» появляются **по наведению**, не висят постоянно;
   - поле подписи под медиа работает, подпись сохраняется после перезагрузки;
   - открой **просмотр** лекции — рамка + подпись на месте, картинка грузится (токен
     `[[file:…]]`), **старые** уже сохранённые картинки/схемы тоже отображаются
     (легаси-парсинг голого `<img>` и `data-type="sketch-block"`).
   - «Заменить картинку» (карандаш у картинки) открывает промпт URL — это осознанный
     минимум; основной путь добавления — drag/paste/slash.

2. **П2 — редактор колоды.** В карточках колоды тот же `<Editor>`. Проверь, что вставка
   медиа там не ломает вёрстку карточки.

3. **П6 — строка группы без названия.** Код только «залатал» отображение (пустое имя →
   «Группа»). Саму строку в БД надо посмотреть: PocketBase Admin → коллекция `groups` →
   найти запись с пустым/пробельным `name`. Реши:
   - если это твоя реальная легаси-группа — задай ей имя;
   - если это оставшийся тестовый/битый owner-only ряд — удали его (или скажи мне —
     добавлю фильтрацию owner-only-групп без членства из списка `/group`).
   `fetchMyGroups` показывает группы, где ты владелец, даже без строки членства
   («подстраховка») — возможный источник «странной» первой строки.

4. **П9 — drag-n-drop, ручная проверка обязательна (Playwright это не гоняет):**
   - **Реордер блоков в конспекте:** наведи курсор на «лист» редактора → слева от абзаца
     должен появиться грип «⋮⋮» → потащи им абзац/пункт списка вверх-вниз, порядок
     должен меняться. (До фикса грип не появлялся вообще.)
   - **Реордер карточек колоды:** редактор колоды → тащи карточку за грип «⋮⋮» в шапке
     карточки → порядок меняется; сохраняется по кнопке «Сохранить колоду».
   - Если где-то всё ещё не работает — напиши, какой именно жест и что видно в консоли
     (F12), тогда добью причину.

5. **П10 — таймстампы, ручная проверка диктовки (нужен Chrome/Edge — в Firefox нет Web
   Speech API).** Открой конспект, включи диктовку из микрофона в шапке, надиктуй
   пару фраз → наведи курсор на надиктованную строку → всплывает время записи. Проверь
   и в **режиме просмотра** лекции (после сохранения). E2E проверяет только слой рендера
   на заранее размеченном абзаце, не саму диктовку.

6. **П8 — микрофон.** Убедись, что тебя устраивает: на «листе» кнопки записи больше нет,
   диктовка — только из шапки приложения и из меню выделения текста. Если на мобилке
   шапка прячется — скажи, вернём компактный триггер.

7. **`apps/web/src/DESIGN.md`** — устаревшая копия корневого `/DESIGN.md` (в ней нет
   подраздела «Чип статуса» и т.п.). Я правил **корневой** `/DESIGN.md` (он — источник
