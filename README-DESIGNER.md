# Cohorta — инструкция для дизайнера

Cohorta — приложение для ведения конспектов лекций (аналог Notion для учёбы).
Этот гайд поможет **за один двойной клик** поднять проект локально на Windows:
интерфейс + бэкенд + готовые демо-данные (12 семестров и логин).

---

## Что нужно установить (один раз)

1. **Node.js LTS (20 и выше)** — <https://nodejs.org> (кнопка «LTS»)
   - после установки перезапусти компьютер или хотя бы закрой/открой терминал
2. **Git** — <https://git-scm.com> (нужен, только чтобы скачать проект)
3. Браузер: Chrome / Edge / Firefox — любой современный

Никаких Docker, баз данных, внешних сервисов и интернет-подключения в процессе работы
не требуется (интернет нужен только на этапе установки).

---

## Шаг 1. Скачать проект

Открой терминал (`Win+R` → `cmd`) и выполни:

```cmd
git clone URL_РЕПОЗИТОРИЯ cohorta
cd cohorta
```

> Если репозиторий закрытый, у Git должен быть доступ (личный токен / SSH).

---

## Шаг 2. Запустить всё одной командой

Перейди в папку проекта и **дважды кликни** по файлу **`start-cohorta.bat`**
(или запусти его из терминала: `start-cohorta.bat`).

Скрипт сам сделает всё остальное:

1. проверит, что установлен Node.js;
2. установит зависимости (`npm install`);
3. если нужно — автоматически скачает **последнюю версию PocketBase**;
4. создаст файл конфигурации `.env` (если его ещё нет);
5. при первом запуске создаст коллекции и демо-данные (миграции);
6. запустит **PocketBase** в отдельном окне и **frontend** в текущем.

Откроются два окна:
- **окно PocketBase** — это бэкенд. **Не закрывай его**, пока работаешь;
- **окно frontend** — здесь крутится само приложение.

---

## Шаг 3. Открыть приложение

Перейди в браузере по адресу:

- **Приложение:** <http://localhost:5173>
- **Админка PocketBase** (работа с данными/коллекциями): <http://127.0.0.1:8090/_/>

### Демо-доступы

| Что | Значение |
|-----|----------|
| Логин приложения | `asyaobraz17@gmail.com` |
| Пароль | `12345678` |
| 12 семестров | готовы сразу, видны в шапке приложения |

В админке PocketBase при первом запуске тебя попросят **создать супер-пользователя**
(любой email/пароль, например `admin@cohorta.local` / `admin123`) — это аккаунт
только для доступа к админке, к приложению он отношения не имеет.

---

## Как остановить

- В **окне frontend** нажми `Ctrl+C` (два раза подряд), чтобы остановить интерфейс.
- В **окне PocketBase** нажми `Ctrl+C`, чтобы остановить бэкенд.
- Или просто закрой оба окна.

Чтобы запустить снова — снова двойной клик по `start-cohorta.bat`.

---

## Частые вопросы

**Проект не запускается, окно «мелькнуло» и закрылось.**
Запусти `start-cohorta.bat` из терминала, чтобы увидеть текст ошибки
(двойной клик закрывает окно сразу после ошибки). Обычно это «Node.js не найден».

**Порт 8090/5173 занят.**
Закрой программы, которые могут занимать порты (другой PocketBase, Vite), либо
перезагрузи компьютер и запусти снова.

**Хочу начать «с чистого листа».**
Удали папку `pocketbase/pb_data/` (внутри — БД и загруженные картинки). Коллекции и
демо-данные пересоздадутся автоматически при следующем запуске.

**Хочу сбросить только данные (оставить коллекции).**
Зайди в админку PocketBase → нужная коллекция → удали записи вручную.

**Антивирус ругается на PocketBase.**
PocketBase — один локальный exe-файл без внешних зависимостей. Добавь папку проекта
в исключения антивируса, если он его блокирует.

## Если что-то пошло не так

Покажи человеку, который работает с кодом:
- текст из окна `start-cohorta.bat`;
- вывод в окне PocketBase;
- скриншот браузера.

## Полезные команды (для продвинутого использования)

```cmd
npm run build          # сборка production-версии (проверка перед сдачей)
npm run lint           # проверка кода
npm run pocketbase     # запустить только PocketBase (без интерфейса)
npm run dev            # запустить только frontend
```
